💡 关于这个后台

网站托管在 GitHub Pages（纯静态、没有服务器），所以：
1. 密码：只是本机门禁（存在浏览器 localStorage），防顺手点开，不防专业攻击；别人打开这个页面看到的是他自己的空数据，你的内容并不会泄露。
2. 数据：访问记录和上传的瞬间都存在「当前浏览器」里，换设备不共享。重要内容记得导出备份。
3. 想要真后台？可以升级：加一台带登录态和数据库的服务（如 Cloudflare Workers + D1），支持真正的账号体系和全网浏览统计。想搞的时候叫我。
